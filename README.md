# The GPS Swears It Was a Shortcut

A Python program that writes the GPS's own one-line excuse for sending the driver down the wrong road to `/output/entry.txt`: it confidently directs the driver to turn right at a stranger's wedding, admits the address was wrong, and defends the detour because the real destination had no cake.

## How to run

```bash
python3 main.py
```

This creates `/output` if needed and writes the entry line exactly to `/output/entry.txt`, printing nothing else.
